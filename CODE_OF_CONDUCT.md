# Code of Conduct

MetricChrono uses the Contributor Covenant Code of Conduct, version 2.1.

## Expected Behavior

- Be respectful and precise in technical discussion.
- Critique ideas, implementations, and claims, not people.
- Keep public project spaces focused on reproducible open-source work.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing private contact details or confidential customer information.
- Using project spaces to promote unsupported safety, medical, financial, or
  robotics deployment claims.

## Enforcement

Maintainers may remove comments, close issues, or block contributors who violate
this code. Report concerns privately through the security/contact channel listed
in `SECURITY.md`.
