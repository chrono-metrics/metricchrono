# Enterprise Boundary

This public repository contains the portable open-core primitive and basic
reproducibility assets. It does not contain production deployment systems.

## Open Source

- core comparator
- ladder
- basic metrics
- smooth surrogate
- adaptive zoom
- coverage meter
- guarded ambient CFAR (Rust core only)
- basic event log
- minimal consensus
- serialization schema
- Rust crate
- Python wrapper
- JavaScript wrapper (optional WASM interop)
- basic examples
- basic benchmarks

## Enterprise

- auto-calibration engine
- domain metric packs
- advanced consensus/reliability engine
- fleet arbitration
- incident replay
- persistent audit logs
- dashboards
- cloud service
- OpenTelemetry, Kafka, Splunk, Datadog, ROS2, SCADA connectors
- security anomaly policies
- robotics deployment packs
- industrial monitoring packs

Production reliability learning, source degradation, split-brain detection, and
fleet arbitration are not part of this public minimal consensus implementation.
